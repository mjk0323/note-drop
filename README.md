# NoteDrop (노트드롭)

> **마니아 층을 타겟으로 스페셜티 커피 취향 추천을 목표로 하는 실시간 피드백 처리 및 한정 상품 출시 시 대규모 선착순 트래픽을 방어하는 백엔드 시스템**

## 🎯 프로젝트 목적
- 비즈니스 모델의 단순 구현을 넘어, 고관여 마니아 도메인의 특성에서 발생하는 백엔드/데브옵스 기술적 과제를 해결하고 검증합니다.
- 순간적인 대규모 선착순 트래픽 제어 및 실시간 데이터 처리 아키텍처 연구를 목표로 합니다.

## 🛠️ Tech Stacks (예정)
- **Backend:** Java 17 / Spring Boot / Spring Data JPA
- **Database:** MySQL
- **Cache/Queue:** Redis
- **DevOps:** Docker / AWS
